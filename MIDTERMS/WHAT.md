# Google Sheets (GSheets)

## Midterm Presentation

This project contains our **Midterm Presentation about Google Sheets (GSheets)**.

## About the Presentation

Google Sheets is a web-based spreadsheet application developed by Google. It allows users to create, organize, calculate, analyze, and share data online.

Our presentation discusses the basic features and functions of Google Sheets and how it can be used in school, work, and everyday activities.

## Topics Discussed

- Introduction to Google Sheets
- Google Sheets Interface
- Creating and Editing Spreadsheets
- Formatting Cells and Data
- Basic Formulas and Functions
- Sorting and Filtering Data
- Charts and Graphs
- Sharing and Collaboration
- Advantages of Google Sheets
- Practical Uses of Google Sheets

## Objectives

At the end of the presentation, the audience should be able to:

1. Define Google Sheets.
2. Identify the different parts of the Google Sheets interface.
3. Use basic formulas and functions.
4. Organize and format data properly.
5. Create simple charts and graphs.
6. Understand how sharing and real-time collaboration work.
